# E05. Справочники

Приоритет: **must-have**. Порядок реализации: **3**.

---

## Цель эпика

Вынести все перечисляемые сущности продукта — города, валюты, ориентировочные веса, запрещённые к перевозке вещи, типы документов — в справочники в базе данных, управляемые из админ-панели.

Проблема, которую решает эпик: заказчик прямо потребовал, чтобы расширение списка городов не требовало правок кода и релиза трёх мобильных приложений. То же справедливо для остальных перечислений: стоп-лист будет пополняться по мере накопления опыта, справочник весов — по мере вопросов пользователей.

Отдельная задача эпика — корректный поиск по городам. Свободный ввод текста сломал бы сервис на первой неделе: «Нячанг», «нячанг» и «Nha Trang» не нашли бы друг друга.

---

## Пользовательские сценарии

- Как пользователь, я хочу выбрать город из списка с поиском, чтобы не гадать, как он пишется в этом приложении.
- Как пользователь, я хочу видеть подсказку, сколько примерно весят документы или упаковка таблеток, чтобы указать вес, не имея весов под рукой.
- Как курьер, я хочу заранее видеть перечень запрещённого к перевозке, чтобы не везти то, за что отвечать мне.
- Как модератор, я хочу добавить новый город за минуту из админки, чтобы открытие направления не зависело от релиза приложений.

---

## Функциональные требования

### Города

5.1. Таблица `cities` с полями: идентификатор, название по-русски, название по-английски, код страны, часовой пояс, признак активности, порядок сортировки, массив синонимов для поиска.

5.2. Поиск по городу ищет по названию на обоих языках и по синонимам, без учёта регистра и раскладки. Запросы «нячанг», «Nha Trang», «yzxfyu» находят Нячанг.

5.3. Неактивный город не предлагается при создании объявлений, но корректно отображается в уже существующих объявлениях и сделках.

5.4. Начальное наполнение — 15 городов:

| Город | Страна | Часовой пояс | Синонимы |
|---|---|---|---|
| Нячанг | VN | Asia/Ho_Chi_Minh | Nha Trang, Камрань, Cam Ranh |
| Дананг | VN | Asia/Ho_Chi_Minh | Da Nang, Danang |
| Хошимин | VN | Asia/Ho_Chi_Minh | Ho Chi Minh, Сайгон, Saigon, HCMC |
| Ханой | VN | Asia/Ho_Chi_Minh | Hanoi, Ha Noi |
| Муйне | VN | Asia/Ho_Chi_Minh | Mui Ne, Фантьет, Phan Thiet |

5.5. Город означает **место передачи посылки**, а не аэропорт. У Муйне своего аэропорта нет — туда добираются из Камрани или Хошимина, и это нормальный сценарий. Аэропорт и номер рейса — необязательные текстовые поля в карточке рейса (E07).

5.6. Доступна любая пара городов в обе стороны, включая пары внутри одной страны. Ограничений по направлениям нет.

### Валюты

5.7. Таблица `currencies`: код, название, символ, число знаков после запятой, признак активности.

5.8. Начальное наполнение: рубль (RUB, ₽, 2 знака), донг (VND, ₫, 0 знаков), сом (KGS, с, 2 знака), тенге (KZT, ₸, 2 знака).

5.9. **Автоматической конвертации нет.** Цены отображаются в той валюте, в которой указаны. Сравнение и сортировка по цене выполняются только внутри одной валюты.

### Ориентировочные веса

5.10. Таблица `weight_references`: название предмета, вес в граммах либо диапазон, категория, порядок сортировки, признак активности.

5.11. Справочник показывается подсказкой рядом с полем веса при создании заявки и при заполнении описи содержимого.

5.12. Начальное наполнение:

### Стоп-лист

5.13. Таблица `stop_list_items`: название, пояснение, категория, код страны (пустой — значит правило действует везде), признак активности.

5.14. Стоп-лист показывается при заполнении описи содержимого и требует явного согласия обеих сторон сделки (E10).

5.15. Стоп-лист используется ИИ-модерацией описи (E13) как жёсткий перечень запретов, дополняющий знания модели о законодательстве страны назначения.

5.16. Начальное наполнение, действующее во всех странах:

| Позиция | Пояснение |
|---|---|
| Наркотические и психотропные вещества | Включая препараты, содержащие их в составе |
| Рецептурные лекарственные препараты | Перевозка возможна только с рецептом на имя получателя и в пределах личной нормы |
| Оружие, боеприпасы, их части и копии | Включая травматическое, пневматическое и сигнальное |
| Взрывчатые и легковоспламеняющиеся вещества | Включая аэрозоли под давлением |
| Литиевые аккумуляторы и павербанки сверх норм авиаперевозки | Ограничения устанавливает авиакомпания |
| Ядовитые, едкие и радиоактивные вещества | — |
| Живые животные и растения, семена, почва | — |
| Скоропортящиеся продукты | — |
| Наличные деньги сверх декларируемых лимитов | Пересечение границы с наличными регулируется таможней |
| Банковские карты и документы на чужое имя | Включая паспорта и доверенности |
| Драгоценные металлы и камни | — |
| Электронные сигареты, вейпы и жидкости к ним | Во Вьетнаме запрещены к ввозу и обороту |
| Алкоголь и табак сверх норм беспошлинного ввоза | Нормы устанавливает страна назначения |
| Любые товары, запрещённые к ввозу в страну назначения | Общее правило |

5.17. Тексты стоп-листа проверяются юристом заказчика перед запуском. В рамках эпика реализуется механизм и приведённое начальное наполнение.

### Типы документов

5.18. Таблица `document_types`: название, код страны, шаблон проверки номера (регулярное выражение, необязательно), признак активности.

5.19. Начальное наполнение: заграничный паспорт РФ, внутренний паспорт РФ, удостоверение личности Республики Казахстан, паспорт Республики Казахстан, паспорт Кыргызской Республики, ID-карта Кыргызской Республики.

### Общие требования к справочникам

5.20. Все справочники редактируются из админ-панели (E16): создание, изменение, отключение. Физическое удаление записи, на которую есть ссылки, запрещено — только отключение.

5.21. Изменение справочника вступает в силу без перезапуска сервиса и без релиза клиентов.

5.22. Клиенты получают справочники через API и кешируют их локально с проверкой версии: справочник отдаётся вместе с меткой изменения, клиент запрашивает обновление только при её изменении.

5.23. Любое изменение справочника записывается в `audit_log` с указанием модератора и значений до и после.

## Критерии приёмки

- [ ] Все пять справочников созданы и наполнены начальными данными из этого документа
- [ ] Поиск города находит Нячанг по запросам «нячанг», «Nha Trang», «камрань» и «yzxfyu»
- [ ] Отключение города убирает его из выбора при создании объявления, но не ломает существующие объявления
- [ ] Справочник весов отображается подсказкой рядом с полем веса
- [ ] Стоп-лист доступен для чтения из приложения и показывается при заполнении описи
- [ ] Добавление нового города через админку появляется в мобильном приложении без переустановки и без релиза
- [ ] Попытка удалить используемую запись справочника отклоняется с понятным сообщением
- [ ] Изменения справочников попадают в `audit_log`
- [ ] Клиент не перезапрашивает справочник, если метка изменения не поменялась

## Технические детали и ограничения

**Поиск с учётом раскладки** реализуется таблицей соответствия клавиш: запрос дополнительно преобразуется из латиницы в кириллицу и обратно, оба варианта участвуют в поиске. Полнотекстовый поиск PostgreSQL для 15 записей избыточен — достаточно поиска по подстроке с нормализацией.

**Кеширование на клиенте** обязательно: справочник городов запрашивается на каждом экране поиска, и ходить за ним в сеть каждый раз недопустимо.

**Часовой пояс города** нужен для тихих часов уведомлений (E14) и для корректного показа дат вылета.
