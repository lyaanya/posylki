# Посылки — ТЗ (домашнее задание)

Короткая версия по формуле школы. Полная спецификация проекта — в [docs/tz](tz/epic-00-overview.md), эта версия её не заменяет.

---

## Что

P2P-сервис попутной доставки посылок. Путешественник продаёт свободное место в багаже, человек, которому нужно передать посылку между Россией и страной проживания, это место покупает.

## Для кого

Русскоязычные экспаты. Приоритетные направления — СНГ и Юго-Восточная Азия (пример: Москва ↔ Нячанг). Продукт конкурирует с СДЭК/карго по цене и скорости, с телеграм-чатами — по доверию за счёт обязательной верификации пользователей по паспорту.

## Экраны (4)

1. **Лента / поиск объявлений** — переключение «рейсы / заявки», поиск по городам, карточка объявления в списке (маршрут, даты, цена за кг, минимальная стоимость, курьер с рейтингом и отметкой верификации).
2. **Карточка объявления** — полная информация о рейсе: маршрут, даты, свободный вес, цена, срок хранения посылки, профиль курьера (рейтинг, число сделок, статус верификации), кнопка отклика.
3. **Создание объявления** — форма по шагам: тип объявления (везу / нужно передать), маршрут и даты, вес и цена, описание.
4. **Профиль пользователя** — статус верификации, рейтинг, число сделок, частые маршруты, отзывы.

## Что НЕ входит

- Оплата и расчёты внутри приложения (эскроу) — деньги между пользователями идут мимо сервиса
- Реальная верификация по паспорту (KYC) — в каркасе только визуальный бейдж «проверен»
- Чат между курьером и заказчиком
- Экран сделки (подтверждение передачи/получения посылки, опись, фото)
- Модерация и админ-панель
- ИИ-разбор свободного текста в объявлении
- Уведомления
- iOS- и Android-клиенты — в этой итерации собран только веб-каркас
- Подключение к реальному бэкенду — экраны работают на статичных моковых данных
