## Как снималось

Каждая страница: сброс вьюпорта → замер реальной высоты через `document.documentElement.scrollHeight` → ресайз окна под эту высоту → скриншот. Технический потолок — около 10000px по высоте (у более длинных страниц, например SkyPtoP, обрезан низ футера).
